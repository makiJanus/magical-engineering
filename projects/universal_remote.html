Universal Remote Controller

▶ Watch it on my YouTube channel!

The Problem

We've all been there: a remote control with more buttons than we'll ever need, and yet, it's missing the simplicity we crave. Tired of the clunky, 30-button behemoths that seem stuck in the 90s, I decided to take matters into my own hands. For this first iteration, I set out to design a universal remote using only the components I had readily available, aiming for a clean, minimalist interface.

Design Philosophy

Building from the ground up, I wanted to move away from the traditional "bar" form factor. While off-the-shelf components are bulkier than a fully custom PCB, this initial prototype prioritizes accessibility and rapid iteration. The goal is a functional proof-of-concept that proves the design's viability.

The controller is built around several key components working in harmony. A central element is the AS5600 magnetic hall-effect potentiometer. Instead of a traditional mechanical encoder, this sensor provides 12-bit angular resolution via I2C. By measuring the angular gradient in each loop of the firmware, I can precisely replicate the "pulse counting" of a standard encoder, enabling smooth and accurate menu navigation.

The user interface is completed with a six-button array. Each button is equipped with its own RC filter to eliminate debouncing issues, ensuring reliable presses. Two buttons are dedicated to fixed functions—OK and Return/Back—while the remaining four are context-sensitive, adapting their function based on the currently selected "face" or mode on the screen.

The core interaction model is simple: select a registered remote control from the menu, then use the rotary encoder to cycle through and choose the specific button function you wish to send. This approach drastically reduces the physical footprint, replacing a sea of buttons with an intelligent, adaptable interface.

To maintain a clear and intuitive user experience, each of the four context-sensitive buttons is assigned a permanent position on the screen: A for upper left, B for bottom left, C for upper right, and D for bottom right. This consistent layout allows for muscle memory and quick, eyes-free operation.

Registering a new remote is a two-fold process. You can pre-program them directly into the source code, or utilize the onboard "learning" mode. In this mode, the controller can "listen" to the IR codes from your existing remote and store them permanently in memory, offering maximum flexibility for the user on the go.

The user interface is brought to life on a vibrant 1.28" TFT LCD display, powered by the GCA9A01 driver. Leveraging the LVGL graphics library ensures a smooth, modern, and responsive visual experience that matches the controller's sleek design.

At the heart of the system lies an ESP32, managed by a custom PCB that integrates the microcontroller, a driver circuit for a haptic feedback motor, and all the necessary connectors for the display, buttons, and sensor array.

Conclusion & Next Steps

This first iteration of the universal remote controller has successfully proven the core concept: a minimalist, context-aware interface that drastically reduces button clutter while maintaining full functionality. The device is completely rechargeable, powered by a custom 3.3V charging circuit that I developed in a previous project, ensuring convenience and sustainability. You can find the details of that design here: 3.3V Charger Circuit.

All mechanical and electronic designs were meticulously crafted using Fusion 360, taking full advantage of its integrated CAD and circuit design capabilities. This unified workflow was particularly valuable, as it allowed me to generate a precise 3D model of the populated PCB. This step was crucial for verifying component clearances and ensuring a perfect fit within the enclosure, eliminating guesswork and costly revisions.

Looking ahead, a second version is already in the works. The next iteration will focus on using a touch screen instead of physical buttons, further refining the user experience, and exploring additional features based on feedback from this initial prototype and a new development board. Stay tuned!
